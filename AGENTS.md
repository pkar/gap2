# Repository privacy

Keep machine-specific configuration and hardware validation records outside
this repository. Do not add personal hostnames, device identities, network
addresses, interface selections, local filesystem paths, pairing state, raw
logs, packet captures, or recorded program audio to tracked files or commit
messages.

Deployment examples must use generic placeholders or external environment
files. Tests may use clearly synthetic addresses, keys, and generated audio.
Document portable capabilities and reproducible checks without identifying the
machines or devices used for private testing.
